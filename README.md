## 🛠️ Tech Stack
- **Framework:** React.js (Vite)
- **Styling:** Tailwind CSS + Custom Romantic Scrapbook & Neon Glow CSS
- **Icons:** Lucide React
- **Animations & FX:** Canvas-Confetti, CSS Keyframe Floats, Starry Canvas, Procedural Web Audio Synth & Audio Player
- **Fonts:** Dancing Script, Great Vibes, Poppins, Playfair Display, Caveat, Sacramento

## 🚀 How to Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/aryan31312007-aryan/our-little-world.git

# 2. Navigate to the project folder
cd our-little-world

# 3. Install dependencies
npm install

# 4. Start the local dev server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
